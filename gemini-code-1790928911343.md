# Quant Investor Tool

## How to Run in Replit:

1. **Connect GitHub Repo to Replit**:
   - Go to Replit -> **New Repl** -> **Import from GitHub** -> Paste your repo link.

2. **Set Up Environment Variables**:
   - Go to Replit **Secrets (Tools -> Secrets)** and add:
     - `FYERS_CLIENT_ID`
     - `FYERS_SECRET_KEY`
     - `FYERS_ACCESS_TOKEN`

3. **Install Dependencies & Start Backend**:
   Run in Replit Shell:
   ```bash
   pip install -r backend/requirements.txt
   python backend/main.py
